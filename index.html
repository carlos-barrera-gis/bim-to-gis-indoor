    What's in the model

    Rooms, levels and equipment came out of the Revit model as IFC, then a Python script (IfcOpenShell) placed them on the map in UTM 13N and wrote Indoors-style fields (FACILITY_ID, LEVEL_ID, UNIT_ID). The network links used by the simulation are modeled for this demo.

    Get the data

    GeoJSON, WGS84.
